# Triage labels

Ánh xạ năm vai trò triage chuẩn sang nhãn dùng trong dự án.

| Vai trò chuẩn | Nhãn trong tracker | Ý nghĩa |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Cần người duy trì đánh giá issue |
| `needs-info` | `needs-info` | Chờ người báo cáo bổ sung thông tin |
| `ready-for-agent` | `ready-for-agent` | Đã đủ đặc tả để agent tự triển khai |
| `ready-for-human` | `ready-for-human` | Cần con người triển khai |
| `wontfix` | `wontfix` | Không xử lý |

Khi skill đề cập một vai trò triage, dùng nhãn tương ứng trong bảng.
Với Local Markdown, ghi nhãn vào dòng `Status:` gần đầu file issue.

Khi đổi cách đặt tên nhãn, cập nhật cột "Nhãn trong tracker".
