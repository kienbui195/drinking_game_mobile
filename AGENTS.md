## Agent skills

### Issue tracker

Issue và spec được quản lý bằng Local Markdown trong `.scratch/<feature>/`.
Trước khi đọc, tạo hoặc cập nhật issue, đọc `docs/agents/issue-tracker.md`.

### Triage labels

Dùng năm nhãn triage mặc định.
Trước khi phân loại hoặc đổi trạng thái triage, đọc `docs/agents/triage-labels.md`.

### Domain docs

Dùng single-context: `CONTEXT.md` ở thư mục gốc và `docs/adr/`.
Trước khi khám phá codebase, đọc `docs/agents/domain.md`.

## Project documentation

Tài liệu của dự án này lưu trong `docs/` theo yêu cầu của user, thay cho MyDocs.
Tài liệu trình bày dùng HTML light theme; hướng dẫn chạy và kiểm thử ở
`docs/implementation.html`, kế hoạch GitHub/Linux ở `docs/deployment-plan.html`.
